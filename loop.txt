C Loops - Short Notes

Loops in C are used to repeat a block of code multiple times.

There are 3 main types of loops in C:

1. for loop
Used when the number of repetitions is known.

Syntax:
for(initialization; condition; update)
{
    // code
}

Example:
for(int i = 1; i <= 5; i++)
{
    printf("%d\n", i);
}

-----------------------------------

2. while loop
Used when the condition is checked before execution.

Syntax:
while(condition)
{
    // code
}

Example:
int i = 1;
while(i <= 5)
{
    printf("%d\n", i);
    i++;
}

-----------------------------------

3. do-while loop
Executes the code at least once before checking the condition.

Syntax:
do
{
    // code
} while(condition);

Example:
int i = 1;
do
{
    printf("%d\n", i);
    i++;
} while(i <= 5);

-----------------------------------

Loop Control Statements

break    -> Stops the loop completely.
continue -> Skips the current iteration.

Example:
for(int i = 1; i <= 5; i++)
{
    if(i == 3)
        continue;

    printf("%d\n", i);
}

Output:
1
2
4
5
